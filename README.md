# java-oopera

Определяем основные классы, переменные:

КЛАССЫ:
Человек - Person, --  актёр - Actor, режиссёр - Director.
Спектакль - Show, -- MusicalShow - Музыкальный спектакль --- балет - Ballet, опера - Opera.
Show:

ПЕРЕМЕННЫЕ:
название                    title                   Show
длительность в минутах      duration                Show
режиссёр                    director                Show
список актёров              listOfActors            Show
Имя актера                  name                    Person
Фамилия актера              surname                 Person
Пол                         gender                  Person
Рост                        height                  Actor
Опыт (кол-во спектаклей)    numberOfShows           Director
Автор музыки                musicAuthor             MusicalShow
либретто                    librettoText            MusicalShow
хареограф                   choreographer           Ballet
кол-во человек в хоре       choirSize               Opera

enum gender();
MALE
FEMALE

Оживляем классы
    -Распечатать текст либретто.
    -Распечатать информацию о режиссёре спектакля — должны выводиться его имя и фамилия.
    -Распечатать список всех актёров, участвующих в спектакле.
        Для каждого актёра при этом должны выводиться имя и фамилия, а также в скобках его рост.
    -Добавить нового актёра в спектакль. При добавлении актёра должна быть проверка, нет ли уже
        такого актёра среди добавленных. Если есть, должно выводиться предупреждающее сообщение,
        и актёр не должен добавляться. Актёры считаются одинаковыми, если у них совпадают имя, фамилия и рост.
    -Заменить одного актёра в спектакле на другого (на вход подаётся объект нового актёра и фамилия того,
        которого он заменяет). Если актёр с такой фамилией отсутствует, должно выводиться предупреждающее сообщение.
        Порядок актёров в списке значения не имеет.


Внутри метода main вам нужно выполнить следующие действия:
-   Создать трёх актеров и двух режиссёров. Также создайте одного автора музыки и одного хореографа
-   Создать три спектакля: обычный, оперный и балет
-   Распределить актёров по спектаклям. Используйте для этого метод добавления нового актёра в спектакль.
        Один актёр может участвовать в нескольких спектаклях.
-   Для каждого спектакля выведите на экран список актёров.
-   Замените актёра в одном из спектаклей на актёра из другого спектакля и ещё раз выведите для него список актёров.
-   Попробуйте заменить в другом спектакле несуществующего актёра
-   Для оперного и балетного спектакля выведите на экран текст либретто.


ПОДСКАЗКА:
Распечатать текст либретто. Так как либретто есть у любого музыкального спектакля,
    будет логично добавить этот метод в класс MusicalShow . Метод должен выводить на экран содержимое поля librettoText .
Распечатать информацию о режиссёре спектакля. Нам нужно описание объекта класса в виде строки,
    поэтому есть смысл переопределить для этого метод toString
Распечатать список всех актеров, участвующих в спектакле. Список актёров есть у любого спектакля -
    поэтому поместим метод в класс Show. Он будет проходить по списку listOfActors и выводить его содержимое на экран.
    Для вывода имени, фамилии и роста также обдумайте использование метода toString
Добавить нового актера в спектакль. Метод должен добавлять актёра в список listOfActors.
    Чтобы сравнивать актёров между собой, вам понадобится реализовать в классе актёра метод equals. Не забудьте,
    что при реализации метода equals обязательно также реализовать и hashCode
Заменить одного актёра в спектакле на другого. Здесь могут быть разные варианты реализации. Можно найти актёра для
    замены, удалить его из списка с помощью метода remove класса ArrayList, а затем добавить нового в конец списка.
    А можно сразу обновить актёра на том же месте, используя метод set
